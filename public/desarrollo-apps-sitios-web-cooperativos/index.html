TECNOLOGÍAS LIBRES PARA DESARROLLO WEB Y MÓVIL

En Geneos creamos plataformas digitales con el desarrollo de apps y sitios web a medida, brindando soluciones que combinan tecnología libre, el diseño centrado en las personas y una fuerte mirada comunitaria. Trabajamos con organizaciones de Argentina y Latinoamérica.

Angular

El framework de desarrollo frontend de código abierto basado en TypeScript, usado para crear aplicaciones web dinámicas.

Django

Facilita la organización del código, mejorando la mantenibilidad, escalabilidad, seguridad e interacción con la base de datos.

React Native

La popular biblioteca de JavaScript para crear aplicaciones móviles para Android e iOS con un mismo código.

DUDAS

Preguntas frecuentes sobre desarrollo web y apps

¿Qué tecnología conviene para mi sitio web?

Depende del proyecto. Para sitios institucionales y de contenidos que tu equipo quiera actualizar solo, solemos usar WordPress. Para tiendas online integradas con stock y facturación, Odoo. Para plataformas con lógica propia, usuarios y procesos complejos, Django y Angular. Y si necesitás máxima velocidad con poco mantenimiento, un sitio estático como este.

¿Desarrollan aplicaciones móviles para Android y iOS?

Sí. Con React Native desarrollamos aplicaciones móviles que funcionan en Android y iOS a partir del mismo código, lo que reduce tiempos y costos de desarrollo y mantenimiento.

¿Mi sitio va a funcionar en celulares?

Sí. Todos nuestros sitios y aplicaciones son responsive: se adaptan a celulares, tablets y computadoras.

¿Voy a poder actualizar el contenido yo mismo?

Sí. Elegimos herramientas que te den autonomía: te entregamos un panel para editar textos, imágenes y productos, y capacitamos a tu equipo para usarlo.

¿También diseñan el sitio?

Sí. Nuestro equipo de diseño y comunicación trabaja la experiencia de usuario (UX), la interfaz (UI) y la identidad visual de cada proyecto.

¿Querés desarrollar tu sitio o tu app?

Contanos tu idea y te armamos una propuesta a medida.
