Apps & Webs

Especialistas en el desarrollo de apps y sitios web cooperativos

TU PROYECTO VIRTUAL

TECNOLOGÍAS LIBRES

En Geneos creamos plataformas digitales con el desarrollo de apps y sitios web cooperativos, brindando soluciones digitales que combinan tecnología libre, el diseño centrado en las personas y una fuerte mirada comunitaria.

Angular

El framework de desarrollo frontend de código abierto basado en TypeScript, usado para crear aplicaciones web dinámicas.

Django

Facilita la organización del código, mejorando la mantenibilidad, escalabilidad, seguridad e interacción con la base de datos.

React Native

La popular biblioteca de JavaScript para crear interfaces de usuario, compatible con múltiples bibliotecas.
